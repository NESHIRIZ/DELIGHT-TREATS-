# Delight Treats — UI Foundation

This repository contains the Sprint 1 (Week 3) project scaffold and UI foundation for Delight Treats. It includes Next.js (App Router) + TypeScript + Tailwind CSS setup and reusable layout components.

## Run locally

Install dependencies:

```powershell
npm install
```

Run development server:

```powershell
npm run dev
```

Build for production:

```powershell
npm run build
npm start
```

Lint:

```powershell
npm run lint
```
